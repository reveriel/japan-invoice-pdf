プライバシーポリシー

制定日：2026年10月12日

本ページは、ウェブツール「適格請求書 作成ツール」（https://www.reveriel.com/japan-invoice-pdf/ 以下「本ツール」といいます）における、利用者情報の取扱い方針を定めるものです。運営者は、本ツールを通じて取得する情報を、以下のとおり適切に取り扱います。

1. 本ツールの基本的な仕組み

本ツールは、すべての処理を利用者のブラウザ内だけで行う静的サイトです。請求書の作成のために入力していただいた発行者名・登録番号・宛先・明細・金額などの内容は、当方のサーバーへ送信されず、外部に保存されることもありません。ページを閉じる（またはリロードする）と、入力した内容は失われます。

したがって、本ツールの利用にあたって、当方が利用者の請求書データを取得・保管することはありません。

2. 取得する情報と利用目的

当方が取得する情報は、次の2つに限られます。

  1. アクセス解析情報 — 本ツールでは、Cloudflare Web Analytics を利用して、ページビュー数や参照元、閲覧環境などの統計情報を取得しています。これは、本ツールの利用状況を把握し、改善に役立てるために利用します。Cookie を用いずに集計される、プライバシーに配慮した解析サービスです。
  2. お問い合わせ・フィードバックの内容 — 本ツールのページに設置しているご意見・フィードバックのフォーム（Google フォーム）からご送信いただいた内容です。これは、ご意見への回答や、本ツールの改善のために利用します。

3. アクセス解析について（Cloudflare Web Analytics）

本ツールは、Cloudflare, Inc. が提供する「Cloudflare Web Analytics」を利用しています。同サービスは、Cookie や localStorage などの端末内の識別子を用いず、個人を特定できない形でアクセス状況を集計するものです。取得される情報には、閲覧したページ、参照元、ブラウザや OS の種類、国・地域などの技術的な情報が含まれる場合があります。

なお、本ツールの表示にはフォント配信サービス「Google Fonts」を、フィードバックの受付には「Google フォーム」を利用しています。これらのサービス提供事業者においては、利用者の IP アドレス等の技術情報が取得される場合があります。各サービスにおける取扱いの詳細は、それぞれの事業者が公表するプライバシーポリシーをご確認ください。

4. 個人情報の保存および第三者提供

本ツールは、請求書の作成に関する入力を含め、利用者を特定できる個人情報を当方のサーバーへ保存することはありません。また、当方は、フォームを通じてご提供いただいた内容を、次の場合を除き第三者へ提供しません。

  • ご本人の同意がある場合
  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要であり、ご本人の同意を得ることが困難な場合
  • お問い合わせ対応等のために、必要な範囲で業務委託先に取り扱いを委託する場合（この場合、委託先を適切に監督します）

5. 安全管理

当方は、取得した情報の漏えい、滅失または毀損の防止その他の安全管理のために、必要かつ適切な措置を講じるよう努めます。本ツールは HTTPS による通信の暗号化に対応しています。

6. 開示・訂正・削除のご請求

フォームを通じてご提供いただいた情報について、開示、訂正、削除等をご希望の場合は、下記のお問い合わせ窓口へご連絡ください。ご本人であることを確認のうえ、法令に従い、合理的な期間内に対応します。

7. お問い合わせ窓口

本ポリシーおよび本ツールに関するお問い合わせは、こちらのフィードバックフォームよりご連絡ください。ご希望があった場合には、お問い合わせ用のメールアドレスを遅滞なく開示いたします。

運営者：GUO XING（詳細は運営者情報をご覧ください）

8. 本ポリシーの変更

当方は、法令の変更や本ツールの内容の変更等に応じて、本ポリシーを変更することがあります。変更後の本ポリシーは、本ページに掲示した時点から効力を生じるものとします。
